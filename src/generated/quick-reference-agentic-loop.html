The agentic loop

What happens between your message and the answer, however many passes that takes.

One turn your message, to the agent finishing

01Assemble

the harness builds the request

System prompt, conversation so far, every tool definition, anything retrieved — sent whole, because the API kept nothing from last time.

from scratch, every pass
System promptStanding instructions the user never sees. Most of what makes two products differ.
The conversationThere is nowhere else for it to live. “Remembering” means it is still in the window.

02Propose

the model’s only move

Out comes either an answer or a structured request to run a named function with arguments. Emitting the request is the whole of what the model does.

it cannot act
Tool useTwo halves in the transcript: a request from the model, a result from something else.
Context windowA ceiling on the request and the reply together. Per call, and it does not refill.

03Check

before anything lands

The harness decides whether the action is allowed: silently, by policy, or by asking you. Where that rule lives is what makes it advice or a mechanism.

this is the “autonomous” step
Approval modeWhich actions need your say-so: all of them, the risky ones, or none.
Human in the loopA person in the path. The tenth prompt in a row is approved unread.
SandboxHolds even when the prompt and the harness are both talked around.

04Act, and take the result

feedback from outside the model

The tool runs and its output goes back into the context — a test failure, an HTTP status, a compiler error. Facts it cannot talk its way around.

then round again
Until done · or the budget runs out

What decides how far it goes

Autonomy level — Set per action class, not per product — usually free on reads, gated on writes, forbidden on a short list.

When the run gets long

Compaction — Older turns swapped for a summary so the run keeps fitting. Lossy on purpose: what mattered only in the original wording is gone.

What outlives it

Session — One run, and everything scoped to it. A new session is a new window.

Long-term memory — Files the harness writes and reads back. Not a faculty of the model.

The loop is the product. A model call answers once; everything you recognise as an agent is this cycle, plus the rules about when it may act.
